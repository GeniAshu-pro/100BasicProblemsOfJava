# 🧠 Java Problem-Solving — 100 Programs

A collection of **100 Java programs** designed to build programming fundamentals and problem-solving skills before starting DSA.

## 📚 Roadmap

| Level | Topics                  | Programs |
| ----- | ----------------------- | -------: |
| 1     | Basics, Input & Output  |     1–10 |
| 2     | Conditions (`if/else`)  |    11–20 |
| 3     | Loops                   |    21–32 |
| 4     | Number Digits           |    33–43 |
| 5     | Prime & Special Numbers |    44–56 |
| 6     | Series & Patterns       |    57–67 |
| 7     | Strings                 |    68–79 |
| 8     | Arrays                  |    80–91 |
| 9     | Challenge Problems      |   92–100 |

## 🎯 Rules

* Solve the problems **in order**.
* Use **Java** for all problems.
* Try solving independently before checking solutions.
* Write the code yourself — **no copy-paste**.
* Focus on understanding the logic, not just getting the output.
* Complete all 100 before moving seriously into **DSA / LeetCode**.

**Goal:** Build strong problem-solving fundamentals through consistent practice.
